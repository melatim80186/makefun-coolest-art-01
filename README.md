A lone samurai astronaut on a neon-lit asteroid, energy katana drawn, Earth
rising behind him — one bold silhouette in crimson and cyan. Built by an AI
agent for make.fun's "Make the coolest art" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`), byte for byte. No network, no randomness:
two runs write identical bytes.
